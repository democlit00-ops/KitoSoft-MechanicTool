# Mechanic Tool v1.0.1

Atualização de correção e acabamento do **Mechanic Tool — by KitoSoft**.

## O que foi corrigido

- Corrigida a edição de atalhos globais.
- Combinações válidas que já haviam sido usadas, como `Shift + 7`, podem ser configuradas novamente normalmente.
- Durante a captura de um novo atalho, os atalhos globais do próprio aplicativo são suspensos temporariamente para não interferirem na leitura das teclas.
- Permanecem reservados apenas os atalhos críticos do programa:
  - `Shift + 0` — zerar a calculadora;
  - `Ctrl + Shift + O` — mostrar/ocultar o overlay.
- Melhorada a notificação ao minimizar para a bandeja.
- A notificação agora usa o nome **Mechanic Tool** e informa de forma mais clara que atalhos globais e overlay continuam funcionando.
- O aviso de minimização aparece somente uma vez por execução.

## Download

Escolha apenas uma versão:

- **Installer:** `MechanicTool-KitoSoft-Setup-v1.0.1.exe` — recomendado para a maioria dos usuários.
- **Portable:** `MechanicTool-KitoSoft-Portable-v1.0.1.zip` — extraia e execute sem instalar.

As duas versões são destinadas ao **Windows x64** e incluem o runtime necessário.

## Atualização

Quem já usa a v1.0.0 pode instalar/usar a v1.0.1 normalmente. Os dados do usuário continuam armazenados na pasta local do Mechanic Tool e não fazem parte dos arquivos de instalação.

## Windows SmartScreen

A v1.0.1 ainda não possui certificado comercial de assinatura de código. O Windows pode exibir um aviso de **editor desconhecido** na primeira execução.

Baixe somente pelos arquivos anexados à Release oficial.

## Apoio

O Mechanic Tool é gratuito. Apoio voluntário via PIX está disponível dentro do aplicativo e no README do repositório.
