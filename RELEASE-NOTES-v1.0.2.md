# Mechanic Tool v1.0.2

Atualização de correção e infraestrutura do **Mechanic Tool — by KitoSoft**.

## 🎥 Tutorial de uso

Assista ao tutorial completo do Mechanic Tool no YouTube:

▶️ **[Mechanic Tool by KitoSoft — Tutorial Completo para Mecânicos no GTA RP](https://youtu.be/KXMfE-bWXl4)**

## 🐛 Correções

- Corrigido o comportamento dos campos **Banco final do turno** e **Dinheiro final do turno** durante um turno aberto.
- Os valores finais agora podem ser alterados repetidamente sem restaurar de forma intermitente o valor anterior.
- O **Lucro previsto** é recalculado imediatamente mesmo quando apenas um dos campos finais é informado e o outro permanece em zero.
- Os valores finais em edição permanecem disponíveis enquanto o turno continua aberto.

## 🔄 Atualizações pelo GitHub

A v1.0.2 adiciona a infraestrutura de atualização do Mechanic Tool.

- Verificação de novas versões em segundo plano, sem bloquear o uso do aplicativo.
- Botão **Verificar atualizações** na tela **Sobre / Apoie**.
- Quando houver uma versão mais nova, o usuário decide se deseja atualizar.
- O Installer é baixado da Release oficial do GitHub.
- O arquivo baixado é validado por **SHA-256** antes de ser executado.
- Após a validação, o Mechanic Tool abre o instalador para o usuário concluir a atualização normalmente.
- A atualização não é instalada de forma silenciosa.

> Importante: usuários da **v1.0.1** precisam instalar a v1.0.2 manualmente. A detecção automática passa a funcionar a partir da v1.0.2.

## 📝 Novidades após atualizar

- Adicionada tela de changelog exibida uma única vez após a instalação de uma nova versão.
- Adicionado botão **Histórico de versões**, que abre as versões publicadas no GitHub.

## 📥 Download

Escolha apenas uma versão:

- **Installer:** `MechanicTool-KitoSoft-Setup-v1.0.2.exe` — recomendado para a maioria dos usuários.
- **Portable:** `MechanicTool-KitoSoft-Portable-v1.0.2.zip` — extraia e execute sem instalar.

As duas versões são destinadas ao **Windows x64** e incluem o runtime necessário.

## 💾 Dados do usuário

A atualização preserva os dados locais do Mechanic Tool. Histórico, configurações e demais dados do usuário não fazem parte dos arquivos de instalação.

Baixe somente pelos arquivos anexados à Release oficial.
