# Privacidade — Mechanic Tool

O **Mechanic Tool — by KitoSoft** foi projetado para funcionar localmente no Windows.

## Dados armazenados

O aplicativo pode armazenar localmente informações como:

- configurações da calculadora;
- atalhos configurados;
- nome definido pelo usuário;
- posição e opacidade do overlay;
- turnos e histórico de ganhos;
- configurações gerais do aplicativo.

Esses dados são utilizados apenas para o funcionamento do Mechanic Tool no computador do usuário.

## Armazenamento local

Os dados principais ficam na pasta de dados local do Windows, dentro da estrutura da KitoSoft/MechanicTool.

## Envio de dados

A versão 1.0.0 não exige conta, login ou serviço online da KitoSoft para funcionar.

O histórico de turnos e os valores financeiros informados pelo usuário não são enviados automaticamente para a KitoSoft.

## Backup

O aplicativo oferece backup e restauração manual. O usuário é responsável por guardar os arquivos de backup em local seguro.

## PIX

A tela de apoio contém dados PIX fixos do projeto exclusivamente para contribuições voluntárias. O uso do aplicativo não depende de pagamento.

## Alterações futuras

Se versões futuras adicionarem serviços online que alterem o tratamento de dados, esta política deverá ser atualizada antes da disponibilização desses recursos.
